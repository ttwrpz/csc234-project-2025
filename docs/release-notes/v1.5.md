## What's in this release

v1.5 lights up the **safety net** on top of the v1.0 ecosystem foundation: a tiered intervention dispatcher that reads the Pattern Engine's daily output, a quote library with a deterministic safety filter, an Insights screen with a non-dismissible bipolar/medical disclaimer ack, the skin system on top of the mood-agnostic token economy, FCM toggle + account deletion + biometric/PIN privacy gate + WebAuthn foundation.

### New features

1. **Tiered Intervention dispatcher** (`features/intervention/`).
   - Reads `users/{uid}/patterns/{date}.triggeredTier` and dispatches at most 1 notification/day, 48 h between notifications, opt-out always available.
   - **Tier 1** = 2-minute breathing screen (`features/intervention/presentation/breathing_screen.dart`) with a real 2-min countdown + inhale/hold/exhale circle animation; CTA "Take a breath" wired into the banner.
   - **Tier 2** = journaling prompt with a free-text composer that writes to a private `users/{uid}/journals/` collection.
   - **Tier 3** = curated quote + crisis resources + Hotline 1323 footer. **Tier 3 messages NEVER call Gemini** (ADR-0012 fence at 5 client layers + 1 server layer).
   - Audit doc written to `users/{uid}/interventions/{id}` with `tier`, `dispatchedAt`, `cooldownUntil`, `optedOut`, `quoteId`.
   - Cooldown doc at `users/{uid}/cooldowns/{type}` enforces the 48 h gap; debug-trigger has a `debug: true` bypass for the Settings → Debug surface only.

2. **Quote Library + Safety Filter** (`features/intervention/domain/quote_safety_filter.dart`).
   - Tier 1 / 2 use Gemini hybrid via `suggestQuote` CF — Gemini suggests, the Safety Filter rejects anything off-script, the dispatcher falls back to the curated pool. Filter is **allow-list, not block-list** — anything not in the pre-approved curated phrase set is rejected by default.
   - **Tier 3 NEVER calls Gemini.** 8 curated phrases pinned in `features/intervention/domain/tier3_curated_phrases.dart`, hash-verified by a startup self-test at app launch. ADR-0012 fence enforced at 5 + 1 layers (see release notes "Architecture" below).

3. **Insights screen + bipolar/medical disclaimer ack** (`features/insights/presentation/`).
   - First visit shows a non-dismissible dialog: "MoodBloom is not a medical device. It cannot diagnose conditions like bipolar disorder, depression, or anxiety. Consult a qualified professional. [I understand]"
   - Persisted to `users/{uid}.insightsDisclaimerAcked: true` via the Firestore-rule one-way `false→true` fence.
   - Disclaimer footer also renders on every tier notification + on Settings → About.

4. **Skin system** (`features/garden/domain/skins/`).
   - Cosmetic-only — never gates therapeutic features.
   - Bought with tokens; **mood-agnostic purchase** — a locked emotion's skin can be unlocked from tokens earned on any positive log day. The `features/skin/` mood-agnostic grep test enforces this at file level.
   - Inventory at `users/{uid}.unlockedSkins: map<emotion, [skinId]>` with a monotonic-up rule on token spend.

5. **FCM toggle + account deletion**.
   - Settings → Notifications master switch wired to Remote Config gate.
   - Account deletion via `wipeUserData` CF that drains `users/{uid}/**` including the new `users/{uid}/security/**` subtree (added in `c1ca5021` after security audit R-H01) and Storage media at `users/{uid}/media/*`.

6. **Biometric reauth with PIN fallback** (ADR-0008 + ADR-0013).
   - `local_auth` with platform Keystore-backed credentials on Android.
   - **PIN fallback** for Web + Android-no-biometric: PBKDF2-SHA-256, 100,000 iterations, 16-byte random salt, hash + salt at `users/{uid}/security/pin`. Server-side rate-limit on the verification endpoint (5 attempts/15 min).
   - History tab + Insights tab gated behind reauth when the privacy toggle is on.
   - Remote Config kill-switch `history_privacy_lock_enabled` lets the team disable the gate without a redeploy if a regression is found.

7. **WebAuthn foundation** (ADR-0014).
   - Cloud Function `webauthnRegisterStart` ships **dark** with two fences: (a) build-time `kEnableWebauthn = false` in the Flutter client; (b) provisioning guard `WEBAUTHN_PRODUCTION_ORIGIN` empty by default in the CF, which rejects every call with 503.
   - Settings tile shows "WebAuthn — coming in v1.5.1" so the surface is discoverable without the path lit.
   - PIN remains the v1.5 web fallback; WebAuthn coexists, not replaces, when it lights up.

### Behind the scenes

- **Tier 3 Determinism Fence at 5 + 1 layers** (ADR-0012). The most safety-critical invariant in the project. See "Architecture" below for the full layer list.
- **`functions/src/suggestQuote.ts`** rejects `tier: 3` at the first line of the handler; the rejection is a unit-tested code path.
- **`features/intervention/domain/dispatcher.dart`** has a hard branch on `tier == Tier.three` that returns `CuratedTier3Phrase.next()` directly — no `AiRepository` import is reachable from the Tier 3 path. A grep test in `intervention/domain/dispatcher_purity_test.dart` enforces this.
- **`firebase/firestore.rules`** lights up the v1.0-stubbed denials on `users/{uid}/interventions/{id}` and `users/{uid}/cooldowns/{type}` with field-level `diff().affectedKeys()` validation. Adds `users/{uid}/security/{type}` with rate-limit + hash-format validation.
- **`firebase/test/firestore_rules.test.ts`** extended to 24 tests (+7 since v1.0 polish) — interventions / cooldowns / security / insightsAck.
- **v1.5 final trim** (`a23480b8`) deleted 78 brittle tests (56 goldens + 22 duplicate-a11y assertions). Zero domain tests removed; spec acceptance cases TC-1..TC-41 all preserved.

## Architecture — Tier 3 Determinism Fence (5 + 1 layers)

This is the load-bearing safety invariant of the v1.5 release. Tier 3 messages — the ones a user in distress will see — must be deterministic and never depend on a non-deterministic LLM call.

| # | Layer | Mechanism | Evidence |
|---|---|---|---|
| 1 | Type system | `enum AiAllowedTier { one, two }` — Tier.three is structurally unconstructible as an AI parameter | `intervention/domain/ai_allowed_tier.dart` |
| 2 | Dispatcher branch | `if (tier == Tier.three) return CuratedTier3Phrase.next();` — hard branch returns before any `AiRepository` symbol is referenced | `intervention/domain/dispatcher.dart` |
| 3 | Unit test | `recordingFake.calls.isEmpty` after dispatching Tier 3 with a recording AI fake | `intervention/domain/dispatcher_test.dart` |
| 4 | Controller test | Re-asserts at the Riverpod controller layer | `intervention/presentation/controllers/dispatcher_controller_test.dart` |
| 5 | Integration test | Full app, only `AiRepository` mocked; runs the dispatcher end-to-end on Tier 3 inputs and verifies zero AI calls | `integration_test/tier3_never_ai_test.dart` |
| 6 | Server schema | `if (tier === 3) return res.status(400).json({error: 'tier_3_never_ai'})` at line 1 of the CF handler | `functions/src/suggestQuote.ts` + Jest |

## Migration notes

v1.5 is read-side-compatible with v1.0 data:

- All v1.0 collections are unchanged.
- New `users/{uid}/interventions/{id}` and `users/{uid}/cooldowns/{type}` collections start empty for existing users; the dispatcher populates `interventions/` on the next tier trigger.
- New `users/{uid}/security/{type}` is created lazily on first PIN setup.
- New top-level user-doc fields default to safe values when missing — no backfill needed.
- Skin inventory at `users/{uid}.unlockedSkins` defaults to an empty map; existing users see no skins until they buy one.

## Known deviations from spec

- **TC-27 (Mann-Kendall worked example).** Tolerance softened to ±0.05 per ADR-0011 (S4 amendment). The user-facing tier-trigger semantics (Z < −1.96) are unchanged.

## Demo script

End-to-end smoke (run on Android emulator + Chrome web):

1. **Bipolar disclaimer ack.** Sign in with a fresh account → Insights tab → non-dismissible dialog appears. "I understand" persists the flag; navigating away before ack returns to Garden.
2. **Tier 1 dispatch.** Settings → Debug → "Trigger Tier 1" → banner shows "It looks like your garden has had some rainy days. Would you like a 2-minute breathing exercise?" → tap "Take a breath" → 2-min countdown + breathing animation runs.
3. **Tier 2 dispatch.** Settings → Debug → "Trigger Tier 2" → "Would you like to write about what's been on your mind?" → journaling composer opens.
4. **Tier 3 dispatch.** Settings → Debug → "Trigger Tier 3" → "We care about you. Here are some resources that might help." + crisis line links + Hotline 1323 footer. **Network trace confirms zero Gemini calls.**
5. **Quote Safety Filter.** Settings → Debug → "Quote Safety Filter test" runs the 55-input adversarial corpus and shows 55/55 rejected.
6. **Skin purchase.** Earn 10 tokens (log 2 moods on a fresh day). Go to Garden → Customize → unlock a sunflower skin → confirm. Token balance debits monotonically; skin appears in inventory.
7. **Account deletion.** Settings → Account → Delete account → confirm. `wipeUserData` runs; `users/{uid}/**` drains; Storage media drains.
8. **Privacy lock.** Settings → Privacy → enable history privacy lock → set 6-digit PIN → log out → log in → History tab requires PIN (or biometric on Android).
9. **WebAuthn tile.** Settings → Privacy → "WebAuthn" tile shows "coming in v1.5.1" with the call disabled.
10. **FCM toggle.** Settings → Notifications → master switch off → debug-trigger any tier → banner does not push (in-app banner only).
