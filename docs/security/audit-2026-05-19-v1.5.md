# Security Posture Report — v1.5 (Sprint 5 demo)

**Status:** Provisional — supplements (does not replace) the v1.0 audit at
`docs/security/audit-2026-05-12-v1.0.md`. The v1.0 doc still describes the
`analyzePatterns` PII fence, the rate-limit collection family, and the
demo-only Remote Config interval — none of those changed in v1.5. Read
this doc for the deltas.
**Date:** 2026-05-19 (the canonical v1.5 demo / tag day per the S5 plan).
**Auditor:** security-reviewer (Claude Code agent profile). The actual
code review happened on a per-PR basis between 2026-05-06 and 2026-05-12;
this supplement consolidates those inline reviews into a single artifact
for the v1.5 release.
**Scope:** all changes between the `v1.0.1` patch tag (commit `d1eaa1df`)
and the `v1.5` release candidate. Specifically, the new `sendCheerUpPush`
Firestore-trigger Cloud Function, the new `deleteAccount` callable Cloud
Function, the four new Firestore rule blocks
(`users/{uid}/settings/notifications`, `users/{uid}/cheerUpEvents`,
`users/{uid}/interventionState/current`, plus the Case 38 schemaV
immutability regression), the AndroidManifest biometric + FCM permissions,
the `flutter_local_notifications` channel registration at app boot, the
`flutter_local_notifications` core-library-desugaring fix, and the
account-deletion UI surface (modal + controller + Settings Danger zone).

This report exists to satisfy the Sprint 5 acceptance bar item:
*"security-reviewer produces a Security Posture Report supplement for v1.5."*
