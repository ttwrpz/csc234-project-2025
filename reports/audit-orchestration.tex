\section{Multi-Agent Team Charter}

Four named subagents under Claude Code:

\begin{longtable}{lll}
\toprule
\textbf{Agent} & \textbf{Authority} & \textbf{Output type} \\
\midrule
architect & System design, ADR/HB authorship & Decision records + handoff briefs \\
flutter-engineer & Dart/Flutter + CF TypeScript & Feature branches with code + tests \\
qa-engineer & Widget/golden/integration tests, sweeps & Test files + sweep reports \\
security-reviewer & Read-only audit of rules/CFs/auth/secrets/deps/PII & Risk register only \\
\bottomrule
\end{longtable}

\textbf{No self-review:} the agent that wrote the code cannot approve its
own work. Two Sprint-3 security audits caught CRITICAL findings (cross-user
queue drain, lost UUIDs) that would have shipped silently otherwise.

\textbf{Plan Mode enforces separation:} every sprint kickoff entered Plan
Mode and produced a written plan file at \texttt{$\sim$/.claude/plans/}.
Architect or orchestrator approves via \texttt{ExitPlanMode} before any
code is written.

\section{Workflow Description}

\textbf{Pipeline:} sprint kickoff (Plan Mode) $\to$ architect drafts ADR +
handoff brief $\to$ flutter-engineer implements + in-PR unit tests $\to$
qa-engineer adds widget/golden/integration tests + a11y + perf sweep
$\to$ security-reviewer audits if rules/CFs/auth/secrets touched $\to$
merge to main / tag.

\textbf{Four CI/hook gates} fire on every commit: \texttt{dart format
--set-exit-if-changed}; \texttt{flutter analyze}; secret scan
(regex blacklist); domain-purity grep over
\texttt{apps/mobile/lib/features/*/domain/}. The preWrite hook in
\texttt{.claude/hooks/settings.json} blocks any \texttt{Write} tool call
into \texttt{*/domain/*} that contains a forbidden import string. Zero
violations across the codebase across all 5 sprints.

\textbf{Tier 3 fence at 5+1 layers} (the architectural invariant
anchoring the entire safety posture): (1) type system; (2) dispatcher
hard branch; (3) unit test; (4) controller test; (5) integration test;
(6) server schema.

\textbf{Firestore rules:} field-level \texttt{diff().affectedKeys()}
validation on every collection; per-user isolation; immutability fences
on \texttt{createdAt}, \texttt{weeklyGardens} (write-once),
\texttt{tokenBalance} (monotonic-up), \texttt{insightsDisclaimerAcked}
(one-way \texttt{false}$\to$\texttt{true}). No HIGH/CRITICAL findings.

\textbf{Cloud Functions:} all four production CFs (\texttt{analyzeMoodText},
\texttt{sendCheerUpPush}, \texttt{suggestQuote}, \texttt{wipeUserData})
in \texttt{asia-southeast1} with rate limits, no PII in logs, no PII in
Gemini payloads (verified by PII canary tests). WebAuthn CF
\texttt{webauthnRegisterStart} ships dark with a provisioning guard.

\section{Lessons Learned}

\textbf{Plan Mode + handoff briefs front-load design.} ADR-0010,
ADR-0011, ADR-0012, HB-007 were the load-bearing examples;
implementation agents had no architectural questions mid-sprint.

\textbf{Multi-layer fences for safety-critical invariants.} The Tier 3
fence at 5+1 layers is more paranoid than typical industry practice; the
cost was modest, the protection is structural.

\textbf{Parallel agents need worktree isolation by default.} Six
salvages in S5 alone; memory now documents 6 failure modes with
recovery procedures.

\textbf{User testing surfaced more than security audits did.} Four
highest-leverage S5 fixes came from a single user opening the app.

\textbf{Golden tests too brittle for a small team on Windows-vs-CI.}
Deleted in v1.5 trim; widget-tree assertions + manual demo coverage
replaced them.

\textbf{Memory compounds.} First salvage cost 30 minutes; sixth cost
five. Codifying recovery procedures in long-lived memory is the
highest-ROI workflow investment a team using AI-assisted enterprise
dev can make.
